# JULIA: актуальное desktop-приложение

Запуск: `julia_desktop\julia_desktop.exe` из корня проекта. В этой папке находятся
единственный EXE приложения, необходимые DLL и копия ресурсов `assets`.
Приложение находит ресурсы относительно EXE, поэтому текущая рабочая папка не важна.
Для переноса приложения копируйте всю папку `julia_desktop`, а не только EXE.

## Управление

| Действие | Управление |
| --- | --- |
| Свободное вращение вокруг модели | Перетаскивание левой кнопкой мыши |
| Приближение / отдаление | Колёсико мыши |
| Панорамирование | Правая или средняя кнопка, либо Shift + левая |
| Перемещение влево / вправо | A / D или стрелки влево / вправо |
| Перемещение вверх / вниз | E / Q или стрелки вверх / вниз |
| Движение камеры вперёд / назад | W / S |
| Выход | Esc |

Вращение выполняется кватернионами и сохраняет возможность проходить через полюса.
Ввод задаёт желаемую позу; каждый кадр камера приближается к ней по аналитическому
решению критически затухающей пружины. Скорость непрерывна при смене ввода,
а интерполяция учитывает время между кадрами. Отклик составляет примерно 0,15 с
до 95% перемещения; бесконечного свободного вращения после отпускания мыши нет.
Зум сглаживается в логарифмической шкале, диапазон дистанций — 0,35–30.
Скорость панорамирования учитывает размер окна, поле зрения и расстояние до модели.

Фон очищается постоянным цветом sRGB `#808080`, без геометрии и шейдера фона.
Освещение, текстуры, контуры и геометрия FBX сохранены. Платформа под персонажем
входит в сам FBX и остаётся частью модели.

## Сборка

Нужны Visual Studio с компонентами Desktop development with C++, CMake, Ninja
и vcpkg. Из PowerShell в корне проекта:

```powershell
.\tools\build.ps1
```

Сценарий сам находит Visual Studio, настраивает среду x64, собирает Release,
обновляет ресурсы рядом с EXE и запускает CTest. Ключ `-SkipTests` пропускает тесты.
Единственный штатный профиль — `vs-release`; промежуточные файлы и зависимости
находятся в `build/vs-release`. При уже настроенной среде доступны команды:

```powershell
cmake --preset vs-release
cmake --build --preset build-release
ctest --preset test-release
```

Для другой модели передайте путь к FBX первым аргументом. Служебный ключ
`--verify` создаёт скрытое окно OpenGL, загружает модель и текстуры из папки EXE,
упражняет обработчики вращения, зума и панорамирования, отрисовывает 120 кадров
и завершает работу с кодом 0 при успехе.

## Структура

- `julia_desktop/` — единственная актуальная сборка для запуска.
- `apps/julia_desktop/` — исходный код desktop-приложения.
- `libs/`, `plugins/` — исходные библиотеки и OpenGL-рендерер.
- `assets/` — исходные модели, текстуры и шейдеры модели; источник копии в сборке.
- `tests/` — тесты; их служебные EXE находятся внутри `build/vs-release/tests`.
- `tools/build.ps1` — воспроизводимая сборка и проверка.
- `build/vs-release/` — текущий каталог CMake и необходимые зависимости vcpkg.
- `configs/`, `cmake/`, `third_party/` — сохранённые конфигурации и компоненты сборки.

Исходная заготовка `apps/julia_sandbox/` сохранена по требованию не удалять исходники;
она не включена в сборку и не создаёт второй EXE приложения.

## Выполненная очистка, 15 октября 2026

Удалены:

- `build/vs-debug/` — старая копия `julia_desktop.exe`, отладочные DLL (включая
  устаревшую `assimp-vc145-mtd.dll`), промежуточные файлы и дубликат зависимостей:
  13 892 файла, 3 521 841 587 байт.
- `build/codex-debug/` — незавершённая конфигурация: 3 файла, 8 701 байт.
- `assets/shaders/background.vert` и `background.frag`, а также их копии
  в папке запуска — неиспользуемые процедурные шейдеры старого фона.
- Профили `vs-debug`, `build-debug`, `test-debug` из CMakePresets.json.
- Код палитры, фонового шейдера, fullscreen-треугольника и его VAO из рендерера.

Пакеты vcpkg текущей Release-сборки, исходники всех библиотек, обе исходные модели,
текстуры и конфигурации сохранены. Тестовые EXE и инструменты зависимостей
не являются альтернативными версиями приложения.

## Проверка результата

Проверено на настоящем контексте OpenGL 3.3 NVIDIA, MSAA 8:

- `core`, `events` — существующие тесты библиотек.
- `orbit_camera` — плавный старт, затухание, точная конечная поза, одинаковая
  промежуточная поза при 30/60/120/240 FPS и неравномерных кадрах, проход полюсов,
  панорамирование, перемещение по трём осям, смена направления и пределы зума.
- `opengl` — загрузка 19 мешей FBX и трёх текстур, отрисовка промежуточных кадров
  вращения/зума/панорамирования, проверка всех пикселей чистого фона на RGB 128,
  сохранение постоянного фона при смене камеры, отсутствие ошибок OpenGL, resize.
- `desktop_launch` — запуск именно `julia_desktop/julia_desktop.exe --verify`
  из `build/vs-release`, загрузка ресурсов из папки EXE и штатное завершение.

Кадры рендера находятся в `build/vs-release/verification`, журнал CTest —
в `build/vs-release/Testing/Temporary/LastTest.log`. Кадры просмотрены визуально.
Проверка ощущений от управления через физический ввод мыши не выполнена:
системный канал Computer Use был недоступен (`native pipe unavailable`).
Обработчики ввода и движение камеры проверены автоматически.
