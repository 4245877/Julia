# JULIA: desktop-приложение

Запуск: `julia_desktop\julia_desktop.exe`. Для переноса копируйте всю папку
`julia_desktop`: EXE, необходимые DLL и `assets`. Ресурсы находятся относительно
EXE, поэтому текущая рабочая папка не важна.

Модель по умолчанию — `Raphtalia_prepared.fbx`: 429 костей, 15 клипов,
24 связанные цветовые карты. 25 из 26 материалов используют текстуры;
геометрия бликов имеет постоянный цвет. [Риг, анимации и глаза](raphtalia/runtime_audit.md),
[актуальные материалы, нормали, тени и ограничения](anime-shading.md).

## Управление

| Действие | Управление |
| --- | --- |
| Свободное вращение вокруг модели | Перетаскивание левой кнопкой мыши |
| Приближение / отдаление | Колёсико мыши |
| Панорамирование | Правая или средняя кнопка, либо Shift + левая |
| Перемещение влево / вправо | A / D или стрелки влево / вправо |
| Перемещение вверх / вниз | E / Q или стрелки вверх / вниз |
| Движение камеры вперёд / назад | W / S |
| Выход | Esc |
| Предыдущий / следующий клип с запуском | PgUp / PgDn |
| Play / pause / resume | Space |
| Stop и точная bind-поза, отключение eye overlay | X или R |
| Loop | L |
| Моргание natural / independent / gaze / head | 1 / 2 / 3 / 4 |
| Шаг с паузой на 1/30 с | `,` / `.` |
| Камера: лицо / общий вид | F / B |
| Список клипов в console | F1 |
| Автономный idle глаз | G |
| Переключение автоматического blink / gaze | H / J |
| Моргание обоими / левым / правым глазом | K / U / I |
| Удержание направления взгляда / нейтральный взгляд | Numpad 1–9 / Home |
| Камера как пространственная цель взгляда | T |
| Средний интервал моргания | `[` / `]` |
| Фиксированный seed поведения глаз | F8 |

По умолчанию работает автономный eye/blink overlay; `--no-eyes` отключает его.
Авторские blink-клипы имеют приоритет. Заголовок показывает клип, время,
loop и FPS. Crossfade и смешивание нескольких клипов пока не реализованы.

Кватернионная камера проходит через полюса. Аналитическая пружина сглаживает
движение независимо от частоты кадров; отклик до 95% занимает примерно 0,15 с.
Зум сглаживается в логарифмической шкале, диапазон дистанций — 0,35–30.
Панорамирование учитывает размер окна, поле зрения и расстояние до модели.
Фон — постоянный sRGB `#808080`, без фонового шейдера и геометрии.

## Сборка и проверка

Нужны Visual Studio с Desktop development with C++, CMake, Ninja и vcpkg.
Из PowerShell в корне проекта:

```powershell
.\tools\build.ps1 -UseInstalledDependencies
.\tools\build.ps1 -UseInstalledDependencies -Configuration Debug
```

Сценарий находит Visual Studio, настраивает x64, собирает приложение,
обновляет ресурсы рядом с EXE и запускает CTest. `-SkipTests` пропускает тесты.
Без `-UseInstalledDependencies` vcpkg устанавливает зависимости; с ним
используются пакеты из `build/vs-release/vcpkg_installed`. Debug использует
тот же каталог зависимостей. Обе конфигурации обновляют одну папку запуска.

При уже настроенной среде чистая Release-сборка и тесты:

```powershell
cmake --preset vs-release -DVCPKG_MANIFEST_INSTALL=OFF
cmake --build --preset build-release --clean-first --parallel 4
ctest --preset test-release
```

Для другой модели передайте путь к FBX первым аргументом. `--verify` создаёт
скрытое окно OpenGL, загружает ресурсы из папки EXE, проверяет callbacks камеры,
отрисовывает 120 кадров и завершает работу с кодом 0 при успехе.

`--verify-animations output_directory` проверяет 15 клипов, точный bind,
24/60/144 updates/s и 3000 переключений с отрисовкой. `--verify-eyes output_directory`
проверяет gaze/blink overlay. Варианты `--review-animations` и `--review-eyes`
показывают проверки в видимом окне. Физический ввод мыши вручную не проверен.

7 ноября 2026 чистая Release-сборка и все 15 CTest suites прошли проверку:
FBX/текстуры, GLSL, материалы, UV-швы и нормали, self/contact shadows,
GL state/resources, skinning, клипы и глаза. Отдельный GPU-аудитор проверил три
модели при вращении камеры, модели и света. После оптимизации все 72 контрольных
изображения совпали с исходным состоянием.

## Структура и служебные файлы

- `apps/julia_desktop/`, `libs/`, `plugins/` — приложение и библиотеки движка.
- `assets/` — модели, текстуры, анимации и шейдеры; BLEND и backups нужны разработке.
- `tests/` — регрессионные тесты; `tools/` — сборка и воспроизводимые проверки.
- `cmake/`, `configs/`, `third_party/` — инфраструктура и конфигурации.
- `build/vs-release/`, `build/vs-debug/` — промежуточные файлы и тестовые EXE.
- `julia_desktop/` — готовая папка запуска; BLEND и backups туда не копируются.

Заготовка `apps/julia_sandbox/` сохранена, в текущую сборку не включена.
`build/anime-audit/` и `build/*/verification/` содержат одноразовые результаты,
не входные данные приложения. После просмотра их можно удалить; тесты создают
кадры заново. Журнал CTest — `build/vs-release/Testing/Temporary/LastTest.log`.
Эти выходные файлы игнорируются Git. Исходники аудита и все тесты сохранены.
