# Метаданные исходных ресурсов

`raphtalia/texturing/` сохраняет авторство, источники текстур, параметры
референса и связи материалов. `restore_reference_textures.py` читает сохранённый
манифест; доступность внешнего источника не требуется для сборки и запуска.

Остальные JSON — provenance подготовки рига и локальных правок геометрии/весов.
Они перенесены побайтово из прежних отчётов. Внутренние даты, hashes и пути
описывают соответствующий этап подготовки и не являются текущим QA.
Итоговый editable источник — `assets/models/Raphtalia_prepared.blend`;
ранние версии находятся в `assets/models/backups`.

Эти файлы не копируются в комплект запуска. Новые кадры, отчёты и промежуточные
экспорты сохраняйте в `build/diagnostics`, а не рядом с метаданными.
