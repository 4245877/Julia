# Эталон второго этапа

`raphtalia_stage2_reference.txt` снят 2026-11-08 в `C:\Julia` **до переноса**
импортёра и глаз второго этапа. Это результат старого `GLModelLoader` первого
этапа, MSVC Release x64, зависимости из зафиксированного `vcpkg.json`.

Первые 28 записей mesh + rig + eyes относятся к обычному импорту
`assets/models/Raphtalia_prepared.fbx`; следующие 28 + rig + eyes — к
`rebuildSmoothNormals=true` (режим приложения). В первом наборе 171 523 вершины,
во втором — 171 550 (repair разделяет вершины на границах жёстких рёбер).
Оба содержат 206 826 индексов, 459 узлов, 429 bindings и 15 клипов.

Формат задан в `../model_asset_snapshot.hpp`: FNV-1a по отдельным семантическим
полям, без padding/адресов/путей; числа сериализуются младшими байтами вперёд,
каждое целое занимает восемь байтов, float/double используют исходные биты.
Mesh хеширует позиции, нормали, UV, IDs/веса, порядок индексов, все параметры
материала, размеры/прозрачность и **все RGBA-пиксели**. Старый путь снимал
вершины перед созданием GLMesh, пиксели — через `glGetTexImage`.
Rig включает точные bind/global матрицы, bind TRS, offsets, иерархию и все ключи.
Eyes включает locals/globals/palette и время проигрывателя при tracking,
ручном моргании, pause/seek/stop на всех 15 клипах.

численный эталон поз — `../legacy_pose_reference.hpp`, сохранённый на первом этапе.
